# Animation

Recipe version 4 adds `animation`: effect (`none`, `typewriter`, `reveal`, `palette-cycle`, `shimmer`, `glitch`), direction, duration (500–20,000 ms), frame rate (1–30 fps), loop, end hold (0–10,000 ms), intensity (1–5) and a glitch seed. Intensity and seed were added within version 4 before any release; records without them take the defaults (3 and 1). Older recipes open with no effect, 2 s duration, 12 fps, looping and a 1 s hold. Animation settings stay when text, style, colors or layout change, and each change is one undo step.

`shared/animation.ts` has the only frame function, `frameAt(model, animation, time)`. It snaps the time to a whole frame (frame *i* is at *i* / fps seconds; looping repeats exactly every duration plus hold, and the last frame lasts until the cycle ends) and always returns the final artwork's rows and columns, so frames never shift or crop. The same function will produce GIF frames.

- **Typewriter** shows the input one character at a time. The renderer draws at most 24 prefixes of the input with the same layout and places each block where the final artwork's block starts, so center- and right-aligned text does not drift while typing. Longer inputs advance several characters per step, and inputs over 300 characters use fewer prefix renders (down to 3 at 2,000 characters) to bound the work. With a maximum width, a word that the finished artwork wraps onto the next line can appear on the earlier line until it is complete; without a width limit, typed text never moves. The last step is the finished artwork, which is held for the end hold.
- **Reveal** wipes the finished artwork into view top to bottom, bottom to top, left to right or right to left.
- **Palette cycle** rotates colors among the font's own color slots (foreground and shadow for Linguaholic Shadow 3D). A font with only a foreground slot moves the foreground through the design's foreground, shadow and highlight colors, and the panel says so. The background never changes. One rotation per duration; the hold shows the original colors.
- **Shimmer** moves a highlight band (intensity + 1 rows or columns wide) once across the visible characters in the chosen direction. Spaces are never highlighted.
- **Glitch** shifts some rows sideways and swaps some cells for other characters already in the artwork, using a seeded generator keyed by seed and frame number. Shifted rows are clipped and padded to the canvas. The finished artwork returns at the end of the duration and stays for the hold. **New glitch pattern** picks another seed.

`frameDataAt` returns a frame's text, its slot colors and its color runs. The preview uses it, and still and GIF exports will too.

The Animation panel previews the selected design in its colors. Transport controls: play/pause, restart, and a frame scrubber (a range input, so arrow keys and touch work) that pauses playback and shows exactly the frame `frameAt` returns for that instant. Timing controls set duration and end hold in seconds and the frame rate from 6 to 30 fps; invalid values show the rule and keep the last valid setting. *Loop* repeats the duration plus hold; *Play once* stops on the last frame, and Play starts it again from the beginning. When the device asks for reduced motion, the preview starts paused; the controls stay available. 

`make test-animation` covers repeatable frames for the same timestamp, frame snapping, loop and play-once indexing, end-hold frames, seeking, identical cell and color data for every preset at every frame, glitch bounds, seed dependence and restoration, palette rotation for mapped and single-slot fonts, and the shimmer band, typewriter canvas size and placement for left, center and right alignment, all four reveal directions, validation and migration. The browser suite covers playback, scrubbing by pointer and keyboard, timing changes and invalid values, play-once stopping, settings kept through text and color edits and reload, preset notes, colors and repeatable glitch frames, fixed preview dimensions, editing with an effect selected, pause, reload and reduced motion.
