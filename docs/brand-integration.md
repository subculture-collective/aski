# Lilac product integration

Studio owns the aski identity. This application consumes the owner-selected Ink Arcade / Lilac pack at subcult-tv commit `9a463b2fe6861e6e991f45fa5f92cdd1c47b848a`; the owner approved Fraunces wordmark/headings and Atkinson Hyperlegible Next controls. `brand/selection.json` lists the 15 selected source/destination mappings. `brand/handoff.json` binds each unchanged asset's hash and byte count to the approved pack manifest `6f28ca35e17244fd3fe520c0d4ff60f153f542e7ed81d4ae5fa733e703d5cf0a`.

Selected outputs are semantic tokens, the ink outlined lockup and pixel mark, favicon/app/share images, three font files and their OFL notices. Private references, prototype HTML, social samples and generator sources are excluded. The product owns its layout and metadata, not new logo masters. Artwork colors remain separate from semantic UI colors.

`make check-brand` checks every imported asset and handoff mapping. To reproduce from a Studio checkout containing the pinned commit, run `node scripts/import-brand.mjs --source /home/onnwee/Work/Worktrees/subcult-tv-aski-brand-pack` to check source/destination hashes, or add `--write` to import. Fetch that commit first. The importer refuses source drift and unexpected destination edits; updating a selection is an explicit reviewable change. CI checks the recorded bundle without fetching another private repository.

The available editor is a compact sidebar and scrollable artwork panel, stacked on phones. Gallery/inspector details arrive with #15 rather than nonfunctional placeholder navigation. Lime identifies the copy action; violet identifies the selected style; focus uses the guide's distinct purple ring. Controls use 44px targets and Atkinson, short headings use Fraunces, and art retains a monospace grid. Reduced-motion removes control transitions. Empty/loading/error, unsupported characters, recovery and permission states keep the same hierarchy and do not move focus.

`tests/brand.spec.ts` checks actual font loading, focus, target sizes, wide-artwork isolation, sign-in dialog focus/return, fragment clearing and reduced motion across the supported browser/viewport projects. Existing catalog, draft, clipboard and account tests exercise the same branded controls. Local inspection and hosted CI are recorded in the issue/PR; a local render is not a deployed release or physical-device qualification.
